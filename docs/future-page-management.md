# 향후 페이지 관리 기능 요구사항

사용자 요청 기록: 2026-10-28.

**지금 페이지 생성·제거·삭제·숨김 기능을 구현하지 않는다.** 해당 기능을 나중에 설계/구현할 때 아래 요구사항을 포함한다.

## 적용 범위

- 이미 새로 만든 모든 페이지.
- 향후 생성/추가하는 모든 페이지.
- 페이지 생성·설정·수정·제거·삭제·숨김을 관리하는 화면.

## 기존 주소 및 301 연결 관리

- 페이지별로 ‘301 리디렉션할 기존 URL’ 입력란을 제공한다. 하나의 새 페이지에 여러 옛 URL을 등록할 수 있다.
- 기존에 조사/저장한 URL 대응 자료에 해당하는 값이 있으면 입력란에 자동으로 채운다. 추정해서 다른 페이지와 연결하지 않는다.
- 관리자 화면에서 기존 URL, 새 페이지 URL, 원래 페이지 제목/내용 요약, 연결 상태를 확인할 수 있게 한다.
- 자동 입력된 값과 직접 추가한 값 모두 사용자가 수정·추가·제거할 수 있어야 한다.
- 기존 페이지와 앞으로 추가할 페이지에 동일하게 적용한다. 칼럼 전용 기능으로 한정하지 않는다.
- 저장한 페이지 연결 정보와 301 내보내기/회사 서버의 리디렉션 설정을 연결한다. 브라우저에만 저장된 상태, 서버 적용 대기, 실제 서버 적용 여부를 구분한다.
- 페이지 URL 변경/삭제/숨김 설계 시 기존 링크의 처리와 연결 목적지도 함께 다룬다. 새 목적지가 없는 주소를 임의로 홈에 보내거나 301 완료로 표시하지 않는다.

## 기존 준비 자료와 연결

- `deployment/redirects/manifest.json`: 기본 URL 대응.
- `deployment/redirects/legacy-inventory.json`: 조사한 기존 URL 목록과 미연결 상태.
- `deployment/redirects/legacy-url-reference.csv`, `.md`, `.json`: 원래 페이지 제목/내용 요약 백업.
- `scripts/build-redirects.mjs`, `deployment/redirects/resolver.mjs`: 회사 서버용 규칙 생성/301 처리.

이 문서는 향후 구현을 위한 요구사항 기록이다. 삭제했던 디자인 모드나 페이지 관리 기능을 지금 다시 생성하라는 요청이 아니다.
