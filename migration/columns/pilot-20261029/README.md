# 가장 오래된 5개 칼럼 시범 이전

사용자가 확인한 5개 글만 포함합니다. 원문 발행일 오름차순으로 /columns/1~5이며 관리자 목록은 큰 번호부터 표시합니다.

- originals/: 원문 본문 HTML 보관. 변경 전 텍스트와 출처를 추적하기 위한 자료이며 실행하거나 별도 게시하지 않습니다.
- report.json: 글별 원본 주소·날짜·작성자, 이미지 원본 URL·자체 저장 경로·SHA-256·파일 크기 대응표.
- url-map.csv: 기존 주소와 신규 번호 주소 대응표.
- ../../.. /cms/imported-columns.json: 현재 스타일로 변환한 게시물 데이터와 기본 작성자 정보.
- 본문 텍스트는 공백 및 기존 빈 문단 정리 외에 수정하지 않았고, 변환 전후 정규화한 텍스트 일치를 검사했습니다. 모든 본문 이미지 주소를 자체 파일로 교체했습니다.
- 원문에 양은미 칼럼니스트가 명시되어 있습니다. 브라우저에 이미 등록한 동일 이름의 작성자가 있으면 그 프로필을 우선 연결하고 중복 생성하지 않습니다. 소속·소개글은 추정해 채우지 않습니다.
- 카테고리는 기존 웰라이프/건강 이름을 우선 연결하고 기본 건강 카테고리를 사용합니다. 새 카테고리는 생성하지 않습니다.
- 브라우저에서 작성·수정한 기존 글은 그대로 유지하고 같은 ID의 수정본을 우선합니다. 전체 과거 글을 추가할 때 발행일 순으로 번호를 다시 계산합니다.
- deployment/redirects/manifest.json에 아임웹 글별 301 매핑을 준비했습니다. 현재 sinor.co.kr 운영 서버의 리디렉션을 변경한 것은 아닙니다.

현재 정적 데이터는 모든 방문자가 읽을 수 있습니다. 관리자 수정은 기존처럼 해당 브라우저에 저장됩니다. 회사 API 전환 시 imported-columns.json의 게시물·작성자와 imageOriginal/imageCrop 등 프로필 정보를 서버로 가져오고 assets/columns/imported 파일을 같이 배포해야 합니다.
