# 과거 칼럼 추가 이전

원문 발행일 순서로 추가하며 기존 데이터를 유지합니다.

- originals/: 원문 본문 HTML
- report.json: 원문 주소·발행일·작성자·카테고리·이미지 자체 경로/해시/크기
- url-map.csv: 기존 주소와 새 번호 주소 대응표
- 본문은 변환 시 텍스트 일치를 확인하고 이미지는 자체 파일로 저장했습니다.
- 기존 카테고리와 작성자를 연결하며 미표기 작성자는 김시놀 / 시놀(주) / 에디터를 사용합니다.
- 리디렉션 설정은 준비 파일일 뿐 운영 서버에 적용하지 않았습니다.
- 사용자 요청으로 커밋·배포 전 로컬 상태로 보관합니다.
