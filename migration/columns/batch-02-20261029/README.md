# 두 번째 과거 칼럼 5개 이전

원문 발행일 기준 6~10번을 추가했습니다. 기존 1~5번 데이터는 유지합니다.

- 원문 본문은 originals/에 보관했습니다.
- 본문 텍스트 일치를 변환 중 확인하고, 이미지를 자체 assets/columns/imported/ 파일로 저장했습니다.
- 원래 발행일을 유지하며 작성자 양은미, 기존 건강 카테고리를 연결합니다.
- report.json에 원본 URL·발행일·이미지 경로·해시·크기, url-map.csv에 이전 주소와 새 주소를 보관합니다.
- 301 설정은 준비 파일만 수정했습니다. 운영 서버에 적용하지 않았습니다.
- 사용자 요청으로 커밋·배포하지 않은 로컬 작업입니다.
