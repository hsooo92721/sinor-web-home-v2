# 시놀 채용 페이지

경로: /recruit/ (정적 서버에서는 /recruit 접속 시 /recruit/로 이동)

시놀 기존 채용 페이지의 내용만 참고하고 원본 디자인·레이아웃은 사용하지 않았습니다. 토스 문화·채용 이벤트 페이지는 사진 중심 첫 화면, 명확한 정보 단계와 포지션 탐색 흐름의 레퍼런스입니다. 토스의 문구·이미지·혜택은 가져오지 않았습니다.

이미지 속 문구 확인: 5fe74c441e65c.png와 37112ff725e0e.png의 인재상 5개, 7aaba19d8b0ea.png의 지원서 작성/서류 전형/면접 1~2회/최종 합격을 텍스트로 반영. 기업문화의 스크롤 전 숨겨진 텍스트도 확인.

히어로: 생성한 연출 이미지 career-hero.png. 실제 직원 사진이나 직원 인터뷰가 아닙니다. 현장 사진 2개와 서비스 화면은 기존 시놀 자료.

jobs-data.json: 5개 원문 포지션의 주요업무·자격요건/우대사항·개발환경·전형을 저장합니다. 현재 채용 여부는 별도 확인 필요하며 현재 모집 중이라는 임의 상태나 마감일을 붙이지 않았습니다. 문의 버튼은 원본 공식 연락처 help@sinor.co.kr 이메일 작성창을 열 뿐, 지원서를 자동 제출하지 않습니다.

새 채용 페이지는 공통 푸터 및 로고·TOP·폰트어썸을 재사용하며, 아임웹으로 돌아가는 링크가 없습니다. 프런트 기능: 직군 필터, 네이티브 포지션 상세 dialog, 3개 복지 탭과 방향키 탐색, 스크롤 등장 효과 및 동작 줄이기, 반응형 지원.
